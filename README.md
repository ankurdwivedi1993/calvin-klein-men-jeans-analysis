# Calvin Klein Men Jeans Analysis

## Project Overview

This project analyzes the Calvin Klein Men Jeans category to identify sales trends, pricing patterns, customer sentiment, and market share opportunities using Excel, SQL, Python, and Power BI.

## Business Objective

- Evaluate category performance
- Monitor pricing trends
- Analyze customer ratings and reviews
- Validate data quality
- Generate actionable business insights
- Build interactive dashboards for decision-making

## Tools & Technologies

- Power BI
- Microsoft Excel
- SQL
- Python

### Data Quality Confirmation (DQC)

- Quality reporting

### Category Analysis

- Brand performance benchmarking
